# SafeWay — 시각장애인 보조 스마트 지팡이

카메라 영상에서 보행 환경을 인식하고, 장애물을 회피할 방향을 판단하여
진동 피드백으로 사용자에게 전달하는 임베디드 보조 기기입니다.

> 인천대학교 컴퓨터공학부 졸업작품 · 4인 팀 프로젝트 · 9개월
> 담당 범위: **영상 처리 파이프라인 및 회피 기동 제어 로직**

---

## 1. 시스템 구성

```
[카메라] → [영상 전처리] → [Semantic Segmentation 추론]
                                      ↓
                            [장애물 영역 검출 / 거리 추정]
                                      ↓
                            [회피 방향 판단 로직]
                                      ↓
                    [GPIO · PWM 제어] → [진동 모터 피드백]
```

## 2. 실행 환경

| 항목 | 사양 |
|---|---|
| 보드 | Raspberry Pi 5 |
| 카메라 | [라즈베리파이 5MP CSI 카메라모듈] |
| 구동부 | 진동 모터 |
| 언어 | Python |
| 주요 라이브러리 | OpenCV, RPi.GPIO |
| 분할 모델 | Fast-SCNN |

---

## 3. 파일 구조

| 파일 | 역할 |
|---|---|
| `safewaymain.py` | 스마트 지팡이 전체 실행 엔트리 포인트. 카메라 입력 수집, 추론 호출, 모터 제어 스레드를 관리 |
| `main_inference.py` | Semantic Segmentation 기반 장애물 인식 및 회피 방향 판단 모듈. 분할 결과에서 장애물 영역을 추출하고 상대 거리를 추정하여 회피 방향을 반환 |

## 5. 기술적 의사결정

### 5.1 Object Detection → Semantic Segmentation 전환

**초기 접근**
YOLO 기반 Object Detection으로 장애물을 인식하도록 구현하였습니다.

**문제**
임베디드 환경의 연산 제약으로 nano 급 경량 모델을 사용해야 했고,
실제 보행 환경에서 탐지율이 요구 수준에 미달했습니다.

**원인 분석**
보행로 경계, 횡단보도와 같이 형태가 불규칙하고 면적이 넓은 대상은
Bounding Box 표현 시 정보 손실이 크다고 판단했습니다.
경량 모델의 성능 한계와 표현 방식의 부적합이 함께 작용한 문제였습니다.

**해결**
픽셀 단위로 영역을 구분하는 Semantic Segmentation 방식으로 전환했습니다.
모델은 실시간 처리를 목표로 설계된 경량 분할 모델인 **Fast-SCNN**을 채택하여,
표현 방식의 문제를 해결하면서도 임베디드 환경의 연산 제약을 함께 만족시켰습니다.
이에 맞추어 학습 데이터 구성과 추론 파이프라인을 재설계했습니다.

### 5.2 분할 결과 기반 거리 추정

별도의 거리 센서를 추가하지 않고, 분할된 장애물 영역의 크기 변화를
기준으로 상대 거리를 추정하는 방식을 설계했습니다.
센서 추가에 따른 하드웨어 복잡도와 연산 부하를 늘리지 않으면서
회피 방향 판단에 필요한 수준의 정보를 확보하는 것이 목적이었습니다.

### 5.3 임베디드 환경 최적화

PC 환경 기준 모델을 그대로 이식할 경우 추론 지연, 발열, 메모리 부족이
발생했습니다. 경량 모델 적용과 입력 해상도 조정으로 연산량을 축소하고,
회피 판단 로직에서 불필요한 연산 단계를 제거했습니다.
